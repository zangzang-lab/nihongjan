## Important rule

Do not use a generic digit-to-word mapping for every numeric expression.

Context can change the reading:

- 一日 = いちにち / ついたち
- 一回 = いっかい
- 一個 = いっこ
- 六個 = ろっこ
- 三羽 = さんわ
- 二羽 = にわ
- 二十歳 = はたち

When no context-aware rule is available, put the record in the numeric review queue instead of guessing.

## Production boundary

These are derived/presentation reading corrections only.

Never change the frozen canonical Japanese sentence merely to make the reading generator easier.
